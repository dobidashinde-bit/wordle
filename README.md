# 🟩 WORD — Wordle

A small Wordle-style word guessing game built with HTML, CSS, and JavaScript.

I made this project to practice JavaScript and build something fun that I could actually play in the browser.

## 🎮 How to Play

The goal is simple:

Guess the **5-letter word** in 6 tries.

For this version, the answer is:

**CRANE**

After submitting a guess:

- 🟩 Green → correct letter and correct position
- 🟨 Yellow → correct letter but wrong position
- ⬜ Gray → letter isn't in the word

You can use either your **computer keyboard** or the **on-screen keyboard**.

## ✨ Features

- 5-letter Wordle-style gameplay
- 6 attempts
- On-screen keyboard
- Physical keyboard support
- Green / yellow / gray letter feedback
- Enter and Backspace support
- Restart button
- Responsive design
- No frameworks or libraries

## 🛠️ Built With

- HTML
- CSS
- JavaScript
